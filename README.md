프로젝트 소개

동적 계산식 기반의 생명표 산출 엔진 설계 및 구현

보험상품별 산출 기준과 계산식을 데이터로 정의하고, Apache JEXL을 활용하여 동적으로 실행하는 생명표 산출 엔진 개발 프로젝트입니다.

개발 환경

Java / Spring Boot

Gradle

Apache Commons JEXL 3.7.0

IntelliJ IDEA

주요 구현 기능

생명표 산출 기준 및 계산식 데이터 구성

경과기간별 적용 산출 기준 선택

Apache JEXL 기반 동적 계산식 파싱 및 실행

단계별 계산 결과 저장 및 후속 계산식 연계

경과기간 간 생존자 수 산출 결과 전달

샘플 위험률을 활용한 계산 결과 확인
